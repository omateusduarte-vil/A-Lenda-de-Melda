# A Lenda de Melda

Zelda-style boss fight game built with Pyxel.

## Requirements

- Python 3.7+
- Pyxel

## Setup

```bash
pip install pyxel
```

## Run

```bash
python main.py
```

## Controls

**Blue character (WASD):**
- W/A/S/D to move

**Red character (Arrow keys):**
- Arrow keys to move

## Game State

- **Luxur** (boss): Center arena, 100 HP
- **Bluu**: Collides with boss and boundaries
- **Redd**: Wraps around edges
